## 🎯 Usage

- **F6** - Open trucker tablet (configurable)
- **F7** - Return rental vehicle (works near depot)
- **ESC** - Close NUI
- **Arrow Keys** - Navigate vehicle carousel
- **Enter** - Rent selected vehicle
